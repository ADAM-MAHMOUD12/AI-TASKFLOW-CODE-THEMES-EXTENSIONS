# TaskFlow Glass

- **Author:** AI TaskFlow
- **Description:** A dark glass-inspired palette with readable contrast.
- **Preview:** Add an optional PNG, JPEG, or WebP screenshot and set its path in `catalog.json`.

## Install

Open the Appearance store in AI TaskFlow and choose **Install**.

## Theme values

The JSON palette changes the editor, sidebar, panel, foreground, and accent colors. The Glass effect is applied by the TaskFlow editor.
